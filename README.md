# Health Monitor Website

A bilingual Flask wellness website with a separate admin panel.

## Run locally
```bash
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

## Admin
Open /admin/login

Development defaults:
- Username: Sujeet singh
- Password: Sujeet@123

For deployment, set SECRET_KEY, ADMIN_USERNAME and ADMIN_PASSWORD as environment variables.

## Important
This project provides general wellness information only. It is not a diagnostic, emergency, or prescription service.
